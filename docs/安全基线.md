# nativedeck 作战安全基线（v1 · 2026-10-25）

> 现场依据：`deckprobe/env17.txt`（2026-10-25 22:44 基线刷新）+ `STATUS.md` 第 12 轮勘误。

## 0. 授权范围

| 维度 | 授权 | 依据 |

| 目标设备 | 仅 `deck@192.168.1.105`（SteamOS，hostname `steamdeck`） | 用户 2026-10-25 明确授权 |
| 认证方式 | 公钥（`BatchMode=yes` 已验证）；**不使用密码认证、不改 `authorized_keys`** | 10-25 异环任务已追加 Mac 公钥 |

## 1. 红线（绝对禁止，违反即中止任务）

1. **不写 rootfs**。现场 `steamos-readonly status = disabled`（可写），因此这条从"物理不可能"变成"必须自律"：
   禁止 `pacman -U/-S/--noconfirm`、`rpm-ostree`、`ostree admin`、`mount --bind /`、`chattr`、任何 `/usr` `/etc` `/var` 写入。
2. **不装/不改 Steam 相关插件组件**。只读确认的位置，一律不碰：
   - Decky：`~/.config/Methodica`、`~/.decky`、Decky 插件目录与 `PluginLoader`
   - 兼容工具：`~/.local/share/Steam/compatibilitytools.d/`（GE-Proton11-11 / dwproton-11.0-15 / LegacyRuntime）
   - 游戏前缀：`~/.local/share/Steam/steamapps/compatdata/`（现有 14 个）
   - Steam runtime：`steamapps/common/SteamLinuxRuntime*`、`~/.var/app/*`、flatpak 列表（含 ProtonUp-Qt）
   - CSS 主题 / ProtonDB Badges / SteamGridDB 等 10-24 部署的插件产物
3. **不重启、不关机、不 `systemctl` 改动、不改 ostree deployment、不动 swap/zram、不改电源与休眠策略**。
4. **不代用户同意任何协议/EULA/账号登录**（沿用既有约定）。
5. **不删既有文件**。删除仅限本任务自建路径，且先列清单再删。
6. **不写入游戏版权内容与密钥**：`.xci/.nsp/.nsz/prod.keys/*.titlekeys` 不入库、不进 GitLab、不外传。
7. **不做 root 提权**（现场 `sudo -n` 需要密码 → 本任务设计上不需要 root，若某步必须 root 则该步标记为「需用户手动执行」并交付命令，不代为执行）。

## 2. 允许写入区（白名单，纯新增）

| 路径 | 用途 | 回滚 |
|---|---|---|
| `~/native-recomp/` | 本项目唯一工作区（已存在，内含已校验的两个 AppImage） | `rm -rf ~/native-recomp` |
| `~/native-recomp/logs/` | 每次运行的 stdout/stderr 归档 | 同上 |
| `~/native-recomp/runtmp/` | `APPIMAGE_EXTRACT_AND_RUN=1` 的解包目标（避开 `/tmp` 与根分区） | 同上 |
| `~/.local/share/lasrecomp/` | LAS 自身数据目录（其运行时自动创建，非手工写入） | 删除该目录（当前仅 6 份日志，无存档） |
| `~/.local/share/containers/` | distrobox/podman 容器存储（用户态、非 root、不在 rootfs） | `distrobox rm -f totk-build` |
| `~/.config/systemd/user/` | **仅当**需要免 GUI 会话常驻时；本轮默认不用 | 删除对应 unit + `daemon-reload` |

写入纪律：备份 → 写 → 逐文件 SHA-256 读回 → 记录回滚链。一次只推进一个变量。

## 3. 资源与稳定性护栏

| 护栏 | 阈值 | 触发动作 |
|---|---|---|
| `/home` 余量 | 基线 264G；下限 < 40G | 停止构建，只报告不清理 |
| 可用内存 | available < 2 GiB | 终止当前负载（按 pid，不 `pkill -f steam`） |
| GPU/CPU 温度 | `edge` > 90 °C 或 `Tctl` > 92 °C | 暂停压测，等待降温 |
| 电源 | 必须 ACAD 在线；电池 < 30% 不跑压测 | 停止负载 |
| 构建时长 | 单条命令 > 25 min | 转后台 + 轮询，避免 SSH 间歇超时丢证据 |
| 前台冲突 | 检测到 gamescope 内游戏进程在跑 | 排队等待，不抢占 |

已知风险（沿用 10-25 结论）：Deck SSH/密码认证存在**间歇会话超时**，根因未闭合。
对策：所有长任务 `nohup` + 落盘日志 + 幂等重入；证据以文件为准，不依赖会话存活。

## 4. 显示环境约束（决定 V1 能否闭合）

10-24 的 5 次 LAS 崩溃根因 = SSH 会话无显示设备（`SDL_Init: No available video device`）。
真机 GUI 验证只允许以下**不改动系统**的投递方式，按优先级：

1. `DISPLAY=:0`（XWayland，`/tmp/.X11-unix/X0` 存在，10-25 已用 `xprop -root` 验证过该通道可投递）
2. `WAYLAND_DISPLAY=gamescope-0` + `XDG_RUNTIME_DIR=/run/user/1000`
3. `mangowc`/`weston --backend=headless` 之类**用户态**合成器 —— 需先在 distrobox 内验证，不装到 rootfs

禁止：改 `start-gamescope-session`、改 seat/logind、重启 display-manager。

## 5. 证据与状态纪律

- 每次真机动作产出 `deckprobe/envNN.txt`（递增编号，不覆盖）+ 一句判定
- 标记只在**看到用户可见结果**后升级：`v1_binary_loads` 已 true；`v1_gui_launch` / `input_validated` / `motion_validated` / `hardware_validated` 未实测一律 false
- `STATUS.md` 只追加；发现自写结论错误 → 追加勘误，不改写原文
- 结论必须标注证据等级：已验证 / 官方声明 / 第三方实测 / 推断 / 未验证

## 6. 中止条件（任一命中立即停止并报告）

1. 需要写 rootfs 或需要 root 才能继续
2. Steam 客户端 / Decky / 兼容工具出现异常迹象（进程消失、配置 mtime 意外变化）
3. 出现非预期的系统级写入（`/etc`、`/usr`、`~/.local/share/Steam` 内文件被本项目触发变更）
4. 设备发热/掉电/掉线连续 2 次
5. 游戏资产（`.xci`/`prod.keys`）缺失 → 该分支标记 blocked 并交付所需清单，不自行寻找或下载 ROM
